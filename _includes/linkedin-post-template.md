# 📣 LinkedIn 포스팅 표준 템플릿 — jjanalysis.com

jjanalysis.com 블로그 글을 링크드인에 올릴 때 쓰는 체크리스트 + 본문 틀 + 월간 콘텐츠 캘린더.

> 이 파일은 내부 작업용 문서다. `_includes/` 안의 파일은 다른 페이지가 `{% raw %}{% include %}{% endraw %}`할 때만
> 렌더링되므로 사이트에 따로 공개되지 않는다. 페이지에 include하지 말 것.

---

## 1. ✅ 포스팅 전 필수 체크리스트

- [ ] **UTM URL 생성** — 캠페인 값은 게시 날짜(`YYYYMMDD`)
  ```
  https://jjanalysis.com?utm_source=linkedin&utm_medium=social&utm_campaign=YYYYMMDD
  ```
  특정 글로 보낼 때는 경로를 붙인다:
  ```
  https://jjanalysis.com/<글 경로>/?utm_source=linkedin&utm_medium=social&utm_campaign=YYYYMMDD
  ```
- [ ] **포스팅 시간** — 화 / 수 / 목, **오전 8–10시** 또는 **점심 12–1시** (참여율 최고)
- [ ] **첫 1시간 댓글** — 댓글 달아줄 지인 1–2명에게 미리 알림

> 💡 `utm_source=linkedin` 링크로 들어온 방문자에게는 사이트 상단에 "링크드인에서 오셨군요! 👋" 배너가
> 자동으로 뜬다 (`assets/js/utm-handler.js`). GA4에서는 *획득 → 트래픽 획득*에서
> `linkedin / social`, 캠페인 `YYYYMMDD`로 포스트별 유입을 구분할 수 있다.
> (사이트의 공유 버튼으로 퍼진 링크는 캠페인이 `share`로 찍힌다.)

## 2. ✍️ 포스트 구조

```
① 후킹 첫 줄        ← 질문 또는 숫자로 시작 ("더 보기" 전에 보이는 건 2~3줄뿐)
        ↓
② 핵심 내용 3줄
        ↓
③ bullet point 3개
        ↓
④ CTA: "전체 분석은 👇" + UTM URL
        ↓
⑤ 해시태그 5개 이내
```

### 복사용 빈 템플릿

```
[① 후킹: 질문 or 숫자 — 예) "S&P 500이 1년에 -20% 빠진 해는 100년 동안 몇 번이었을까요?"]

[② 핵심 1]
[② 핵심 2]
[② 핵심 3]

• [③ 포인트 1]
• [③ 포인트 2]
• [③ 포인트 3]

전체 분석은 👇
https://jjanalysis.com/<글 경로>/?utm_source=linkedin&utm_medium=social&utm_campaign=YYYYMMDD

#한인투자자 #JJAnalysis #FinTech #KoreanDiaspora #주식분석
```

### 작성 팁

| 항목 | 기준 |
|---|---|
| 첫 줄 | 숫자(%, 연도, 금액) 또는 질문. 결론을 다 말하지 말고 궁금하게 |
| 길이 | 본문 1,300자 이내. 문단마다 빈 줄로 띄우기 |
| 링크 | 본문에 UTM URL 1개만. 여러 개 넣지 말 것 |
| 이미지 | 사이트 차트 스크린샷 1장 첨부하면 체류·클릭이 늘어남 |
| 해시태그 | 기본 5개 중 글 주제에 맞게 1~2개 교체 가능 (총 5개 이내 유지) |
